# Ícones — padrão Lucide (ISC)

Biblioteca: `lucide-icons/lucide` — https://github.com/lucide-icons/lucide
Licença ISC. Uso comercial liberado. 1600+ ícones, grid 24px, stroke 2px,
`stroke="currentColor" fill="none" stroke-linecap/linejoin="round"`.

Regra do template: **não colar paths proprietários**. Copie o SVG do site
lucide.dev (código MIT-like via ISC) ou use o sprite inline da página
`homolog-generica.html` como base. Todos os ícones abaixo já estão com
paths simplificados estilo Lucide.

| Uso no catálogo | Nome Lucide | Onde usar |
|---|---|---|
| Sacola | `shopping-bag` | Abrir lista / carrinho |
| Buscar | `search` | Campo de busca |
| Adicionar | `plus` / `minus` | Qtd e "Quero" |
| Fechar | `x` | Gaveta, modal, filtros |
| Confirmar | `check` | Toast, passos |
| Entrega | `truck` | Prazo/frete |
| Garantia | `shield-check` | Selos de confiança |
| Avaliação | `star` | Depoimentos |
| Favorito | `heart` | Wishlist futura |
| WhatsApp | `message-circle` * | Botão zap (desenho próprio, marca) |
| Instagram | `instagram` | Rodapé |
| Local | `map-pin` | Retirada local |
| Horário | `clock` | Prazo produção |
| Filtro | `sliders-horizontal` | Ordenar/filtrar |
| Seta | `arrow-right` | CTAs secundários |
| Loja | `store` | Logo placeholder |
| Caixa | `package` | Card sem foto |

\* WhatsApp/Instagram são marcas: Lucide não distribui brand icons com a
mesma liberdade. Mantemos traço próprio simples e neutro; lojista pode
trocar pelo asset oficial da marca quando quiser.

Acessibilidade: todo ícone decorativo usa `aria-hidden="true"`. Ícone com
ação usa `aria-label` no botão, nunca só no SVG.

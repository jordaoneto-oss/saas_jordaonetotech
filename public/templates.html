Como personalizar

O painel lateral é o mesmo nos três modelos. Tudo o que você muda fica salvo neste navegador até restaurar o original.

1

Seções

Arraste para reordenar, use as setas ou o olho para ocultar um módulo sem apagar o conteúdo.

2

Conteúdo

Edite capa, selos, produtos em destaque, coleções, depoimentos e rodapé com campos guiados.

3

Tema

Aplique um preset, ajuste cada cor e troque as fontes de título e texto. O contraste acompanha.

4

Publicar

Exporte o JSON, teste no celular e use o mesmo arquivo como base do tenant na produção.

Criar uma loja com o modelo

Na produção local, o clone lê saas/templates/<id>/ e aplica o tema sugerido do meta.json.

Pelo painel

Em Painel SaaS → Lojas → Nova loja, escolha o modelo e o tema. O formulário já lista os templates encontrados em saas/templates/.

  • Modelo: vitrine-hml, editorial-hml ou boutique-hml
  • Tema inicial: vitrine, editorial ou boutique (ou outro preset)
  • O clone troca nome, WhatsApp, catálogo, imagens e manifesto — o restante vem do seed.

Dica: use o botão Exportar no personalizador para guardar a configuração validada em HML.

Pela API local

O mesmo payload usado pelo painel:

// POST /api/saas/lojas
{
  "slug": "minha-loja",
  "nome": "Minha Loja",
  "zap": "5511999999999",
  "template": "vitrine-hml",
  "tema": "vitrine"
}

Os temas vitrine, editorial e boutique estão em saas/temas.json e em /api/temas.
